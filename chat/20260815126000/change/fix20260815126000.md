 ## 变更内容
 修复第三轮代码审查报告中的 5 项问题。
 
 ## 修复项
 1. **ChatArea.vue** — fallback 非流式请求超时从 120s 缩短为 30s，避免用户等待过长
 2. **ChatArea.vue** — 纯图片发送时 content 设为 `[图片]`，避免 API 不接受空文本
 3. **ChatArea.vue** — error-toast 添加 `max-height: 120px` 和 `overflow-y: auto`，防止极长错误信息超出视口
 4. **MessageBubble.vue** — fadeIn 动画移除 `transform: translateY(4px)`，避免动画期间影响 lightbox 的 fixed 定位
 5. **ConfigModal.vue** — `modal-left` 添加 `flex-shrink: 0`，并在 `max-width: 480px` 下隐藏左侧列表，窄屏表单不再拥挤
 6. **ToolBar.vue** — `.select-dropdown` 添加 `max-height: 300px` 和 `overflow-y: auto`，配置项过多时不再超出视口
